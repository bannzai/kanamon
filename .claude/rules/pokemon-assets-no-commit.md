# ポケモンの画像・データをリポジトリに commit しない

本リポジトリは public であり、ポケモンのスプライト画像・名称データ等の素材は The Pokémon Company の著作物のため、commit すると「個人的・非商業的な家庭内利用」(公式ファン条項) を超えた公衆への再配布になる (意思決定と根拠: [ADR 0001](../../documents/adr/0001-pokemon-assets-testflight-personal-only.md))。

## ルール

- ポケモンのスプライト画像・公式アートワーク・名称一覧などの素材ファイルを、形式 (png / json / plist / Asset Catalog 等) を問わずリポジトリに追加しない。アプリバイナリへの同梱 (bundle リソース化) もしない
- ポケモンのデータは実行時に PokeAPI から取得し、端末内 (Caches ディレクトリ・SwiftData) にのみキャッシュする
- 開発・検証用にローカルへダウンロードする場合は gitignore 済みのディレクトリ (`tmp/` 等) に置く
- コミット前に、差分に画像ファイル・素材データが含まれていないかを確認する。テスト用のモックデータは、実在のポケモン名・画像ではなく架空の名前 (例: 「テストモン」) を使う
- 配布は TestFlight の個人利用に限定する。App Store 申請・外部公開の作業を行わない
