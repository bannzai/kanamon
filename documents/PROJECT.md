# kanamon (カナモン)

ポケモンの名前でカタカナ・ひらがなの読みを練習する子ども向け iOS アプリ。

- 企画の起点: https://github.com/bannzai/IdeaMemo/issues/189
- 配布: **TestFlight のみの個人利用** (自分の子ども向け)。App Store には公開しない
- リポジトリ: public (コードのみ。ポケモンの画像・データは commit しない。[ADR 0001](adr/0001-pokemon-assets-testflight-personal-only.md))

## コンセプト

「好きなキャラクターの名前を読みたい」という内発的動機でカタカナ (とひらがな) の読みを覚える。ポケモン図鑑でカタカナを覚えたという体験談が複数あり (例: https://note.com/papa_gakushu/n/n92fe26435e80 )、それをアプリの形にする。

- 対象: 未就学児〜小学 1 年生 (カタカナは小 1 の 2 学期に短期間で履修するため、先取り・補強の需要がある)
- ポケモン名はカタカナの網羅性が高い (「ツ」「ヌ」等の低頻度文字も数百種の名前でカバーできる)
- カタカナ名は機械的にひらがな表記へ変換できるため、ひらがなモードも同じデータで提供できる

## MVP 機能

1. **ずかん**: ポケモンの一覧 (第 1 世代 151 匹から開始)。スプライト + カタカナ名。ゲット済み / 未ゲットの表示
2. **よみれんしゅう**: 1 匹ずつ大きく表示し、名前をカタカナ / ひらがな切替で表示。タップで読み上げ (AVSpeechSynthesizer)
3. **クイズ**: 絵に対して名前の 4 択 (読めたらゲット)。正解でずかんに登録
4. **進捗保存**: ゲット状況を SwiftData でローカル保存

## 技術構成

- iOS 17+ / SwiftUI / SwiftData (ローカルのみ。[ADR 0002](adr/0002-local-only-infra.md))
- ポケモンのデータ (日本語名・スプライト画像) は初回起動時に PokeAPI ( https://pokeapi.co ) から取得し、端末内にキャッシュする。リポジトリ・リモートには置かない
- マネタイズなし (完全無料)。アカウントなし。Analytics なし
- 検証: Makefile (`make build-ios` / `make ios` / `make test`)。AGENTS.md「検証方法」参照

## 事前調査の要点 (2026-08-25)

詳細はリポジトリの事前調査 issue を参照。

- **権利**: PokeAPI のスプライトは The Pokémon Company の著作物 ( https://github.com/PokeAPI/sprites/blob/master/LICENCE.txt )。公式ファン条項は「個人的・非商業的な家庭内利用」限定 ( https://www.pokemon.com/us/legal/information )。よってストア公開は不可、TestFlight の個人利用と画像非 commit を前提にする
- **市場**: ひらがな・カタカナ学習アプリは「無料 + 広告なし」か「買い切り」が高評価。キャラクター名読みに特化した専用アプリは見当たらず、切り口としては新規 (ただし個人利用のため市場性は問わない)
- **需要**: カタカナは小 1 の 2 学期に 2〜3 週間で履修。「ポケモンでカタカナを覚えた」体験談が個人ブログ・note に複数存在する
